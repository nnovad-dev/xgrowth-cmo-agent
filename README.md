# xGrowth CMO Agent

An AI Chief Marketing Officer skill that audits websites and coordinates specialist agents across SEO, AI search visibility, content, Reddit, Hacker News, and X.

## Install

Copy .agents/skills/cmo-agent/ into your Codex workspace, then ask Codex to act as your CMO for a website URL.

## Included

- CMO orchestration instructions
- Six specialist agent briefs
- Local website audit script

## Requirements

- Python 3
- Web access for live research
- Optional Google PageSpeed Insights API key

## Privacy

This repository contains only the reusable agent. Private client data and the xGrowth knowledge archive are not included.
